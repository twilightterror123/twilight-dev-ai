# Twilight Dev AI

Developer AI assistant built with Next.js and the Vercel AI SDK.

## Features
- Developer chat
- Debug mode
- Explain code mode
- Improve/refactor mode
- Create-code mode
- Streaming responses
- Responsive dark Twilight UI
- Server-side AI configuration

## Setup

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` and configure your AI provider. Never expose API keys in `NEXT_PUBLIC_*` variables.

## Vercel

Import this repository into Vercel and add the same environment variables in the project settings.
